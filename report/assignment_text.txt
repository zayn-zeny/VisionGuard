VisionGuard Assignment: AI vs Real Image Classification and 
Deployment 
1. Overview and Rules 
You will build VisionGuard, a web service that tells whether an uploaded image is AI-generated or real. 
You will train a TensorFlow/Keras model, track every experiment with MLflow on DagsHub, serve the 
model through a Flask web app, log every request in a database, containerize everything with Docker 
Compose, and deploy it to the cloud. 
Deliverables: (1) a PDF report with screenshots, (2) a GitHub repository, (3) a public or shared DagsHub 
project, (4) a live URL. Marks total 100 (Section 10). 
Rules 
• You may use any cloud (Oracle, Vercel, Google, AWS, Azure) for Task 7.  
• Create Dagshub Repository for code, data and model versioning.  
• Project Name is Your [Roll Number_A2_Ops] (Everywhere) Cloud/DAGSHUB etc.  
2. Dataset 
Dataset: AI Generated Images vs Real Images  (https://www.kaggle.com/datasets/cashbowman/ai-
generated-images-vs-real-images) on Kaggle. It is a two-class collection: images scraped from websites 
(real) and images produced by generative AI (AI-generated), covering subjects such as people, animals, 
portraits and landscapes. The label of an image is the folder it sits in.

7. Task 5: Database Trail (8 marks) 
Goal: every request leaves a permanent, queryable record that answers: what was decided, when, by 
which model, and how confidently. 
You have to create a database (SQLITE/Redis/Postgres) and must attach in Flask views to keep history of 
the searches. Whenever, any search is made and model returns the results, the entry should be made in 
database. There should be a history menu in HTML, CSS where users may be able to view history of the 
searches, also what was decided, when, by which model, and how confidently.
